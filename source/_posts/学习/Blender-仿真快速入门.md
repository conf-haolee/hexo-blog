## 02 blender python安装

```
pip install bpy
```

pip 失败时，尝试离线安装

```
pip install bpy-4.1.0-cp311-cp311-win_amd64.whl && bpy_post_install
```

下载地址：https://pypi.tuna.tsinghua.edu.cn/simple/bpy/

注意在指定python环境下下载
